## 2026-06-11 - Canvas Game Accessibility Hints and Focus
**Learning:** Canvas-based games lack innate interaction discoverability and native focus states. Without explicit HTML instructions outside the canvas and strong focus-visible styles on overlay buttons, keyboard and screen reader users are left guessing.
**Action:** Always provide explicit HTML text hints for core controls outside the <canvas> element and ensure custom interface elements like overlay buttons have clear :focus-visible styles to support keyboard navigation.
