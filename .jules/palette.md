## 2024-04-03 - Interactive Elements Focus Visibility
**Learning:** Custom interactive elements in the game UI (e.g., buttons, links) require explicit focus indicators because default browser outlines can blend into the dark background, harming keyboard accessibility.
**Action:** Standardized `:focus-visible` outline pattern (`2px dashed #FFFFFF` with `4px` offset) applied to ensure visibility and accessibility across all interactive components.
